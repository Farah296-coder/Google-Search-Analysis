# 📊 Google Search Analysis

## 📖 Overview

This project analyzes Google search trends using Python and Google Trends data. The collected data is stored locally as a CSV file to minimize repeated requests to Google Trends and improve analysis efficiency. The project focuses on exploring search interest over time, comparing multiple keywords, analyzing regional popularity, and visualizing search trends through various data analysis techniques.

---

## 🚀 Features

* Import and process Google Trends data
* Save collected data as a CSV file
* Load stored data for offline analysis
* Compare search trends for multiple keywords
* Calculate average search interest
* Analyze monthly search trends
* Generate a correlation heatmap
* Identify the highest search interest dates
* Apply a 7-day moving average for trend smoothing
* Create visualizations using Matplotlib and Seaborn

---

## 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* PyTrends

---

## 📂 Project Workflow

1. Import the required libraries.
2. Connect to Google Trends using PyTrends.
3. Collect search trend data for selected keywords.
4. Save the retrieved data as a CSV file.
5. Load the stored dataset for analysis.
6. Compare search trends over time.
7. Calculate the average search interest.
8. Analyze monthly search patterns.
9. Generate a correlation heatmap.
10. Identify peak search interest dates.
11. Apply a 7-day moving average to smooth search trends.

## 📊 Visualizations

The project includes the following visualizations:

* Google Search Trends Comparison

## 📌 Output

The project provides visualizations and insights into keyword popularity over time. It enables users to compare search trends, identify peak interest periods, analyze monthly patterns, and better understand search behavior using Google Trends data.
